PAHLAWAN INDONESIA - UTS

Project Android Studio Java + XML dengan Custom ListView.
Package: com.herdiawan.f52124016.aplikasi_uts

Perbaikan build:
- Menghapus dependency AndroidX AppCompat yang memicu konflik Kotlin duplicate class.
- Menggunakan Activity bawaan Android SDK.
- Tidak menggunakan library Kotlin/AndroidX eksternal.

Cara menjalankan:
1. Buka folder PahlawanIndonesia di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pastikan vivo V27 terdeteksi.
4. Klik Run (segitiga hijau).
